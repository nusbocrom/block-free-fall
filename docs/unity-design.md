# ブロック自由落下 Unity版 設計メモ

Web版(`index.html`、Matter.js)の仕様をまとめたもの。Unity版を作るときの設計書として使う。
数値はMatter.jsでの値。Unity(Box2D)では挙動が違うので、遊んで合わせ直すこと。

## ゲームの流れ
- 画面上部にピースが出て、プレイヤーが位置と向きを決めて落とす。落とすまでピースは動かない。
- 前に落としたピースが止まる(約0.75秒静止、または7秒経過)と、次のピースが出る。
- お椀から落ちたピースは1回のミス。ミス3回でゲームオーバー。
- 記録は「最高到達点(m)」と「乗せた個数(最多)」。ベストはm。

## 土台
- なだらかなお椀型。中央が最も低く、縁が30(約1マス)高い。半幅は150。
- 放物線を短い板の連続で作る(20分割、厚さ30)。

## ピース
- 7種(I, O, T, S, Z, J, L)。1マス=30。色は青緑、黄、紫、緑、赤、青、橙。
- 変な物体(4種、色はほぼ黒 `#2a2d38`): 片側が重いダンベル、トゲの星(棒3本)、巨大三角、鉄球。

## 物理の値(Matter.js)
| 項目 | 値 |
|---|---|
| 重力 | 0.9 |
| 落下速度の上限 | 9(着地の衝撃を抑える) |
| 摩擦 / 静止摩擦 | 0.15 / 0.3 |
| 反発 | 0.1 |
| 密度 | 0.0012 |
| 変な物体の重い部分 | 密度×1.5 |

## 操作
- スマホ: 画面を押している間、ピースが指のx座標についてくる。右(または左)の縦スライダーで回転(-180〜+180度、10度刻み)。⬇ボタンで落とす。
- スライダーの左右は利き手に合わせて切り替え。
- PC: ←→で移動、↑↓で回転(長押しで連続)、Space/Enter/右クリックで落とす、ホイールで回転。
- 落下位置の目安として、ピースの左端・右端から真下に点線を2本。

## 変な物体の襲来
- 塔が5mに達すると、黄黒の注意の帯と「ぎゅいーん」のサイレンが約1.8秒。そのあと変な物体が1つ出る。
- 以降は、出た時点の高さから4mごと。

## 直前に戻る(広告で復活)
- ピースを落とす直前の状態(全ピースの位置・角度・速度、持っていたピース)を毎回覚える。
- ゲームオーバー画面から1回だけ、広告を見て直前に戻れる。ミスの残りは+1。

## 広告
- 広告ウィンドウ: 枠の中に広告を出し、5秒後に「戻る」が押せる。
- 場面: 直前に戻る(リワード)、ゲーム間(10回に1回)。
- 広告の呼び出しは1か所(`Ads`)に集約し、広告会社を差し替えられる形にしてある。
- 方針: Ad-Virtuaの使用を検討(落とすブロックに広告を入れる案)。審査で可否が決まる。

## 結果画面・シェア
- 背景に、最高到達時の塔を薄く表示。
- シェア: 高さ・個数・ハッシュタグ(`#ブロック自由落下 #クソゲー作ります`)+最高到達時の画像。

## 音(すべて合成音)
- ぶつかる音(強さで変化)、積むと上がる音(ペンタトニック)、落とす、ミス、サイレン、変な物体の「ドン」、ゲームオーバー、直前に戻る。
- ミュートあり。広告の再生中は鳴らさない。

## 表示
- ライト/ダークの切り替え(初期はライト)。PCは9:16の縦長の枠。

## Unity版で決めること
- 物理: Box2D(Rigidbody2D、PhysicsMaterial2D)で、複合形状(ピース)の作り方。
- 画面: 縦固定、カメラの引き(塔が高くなると縮小)。
- 広告: Ad-Virtua(ブロック内)とAdMob(リワード)の使い分け。
- 保存: ベスト記録、ミュート、テーマ、利き手(PlayerPrefs)。
