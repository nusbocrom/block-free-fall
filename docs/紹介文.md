公開ページ: https://nusbocrom.github.io/block-free-fall/
サムネイル: `unity/Captures/thumbnail.gif`(撮り方は「サムネイルGIFの撮り方」を参照)

## 短い紹介(SNS・一覧向け、約100字)

```
お椀型の土台にブロックを落として、どこまで高く積めるかを競う物理パズル。積むほどグラグラ、高くなると変な物体まで降ってきます。スマホのブラウザですぐ遊べます。
#ブロック自由落下 #クソゲー作ります
```

## 紹介文(ゲームのページ向け)

```
お椀型の土台に、7種類の形のブロックを1つずつ落として積み上げる、物理演算のゲームです。

ブロックは指でつかんで位置を決め、スライダーで向きを変えて、好きなタイミングで落とします。
ところが土台はお椀の形。少しずれただけで、ブロックはツルッと滑り、塔はあっけなく崩れます。

塔が5mを超えると、サイレンとともに、ダンベルや鉄球などの変な物体が降ってきます。
お椀から3回落としたらゲームオーバー。1回だけ、落とす直前に戻ってやり直せます。

記録は「最高到達点」と「乗せた個数」。結果は、最高到達時の塔の画像つきでシェアできます。

スマホのブラウザで、登録なし・無料で遊べます。PCでも遊べます。
※ゲーム内に広告が表示されることがあります。
```

## 遊び方

```
【スマホ】
・画面を押している間、ブロックが指についてくる
・画面の端のスライダーで回転(10度ずつ。左右は「回転:右/左」で切り替え)
・下の「↓」ボタンで落とす

【PC】
・←→ またはクリックで移動、↑↓ またはマウスホイールで回転
・スペース、Enter、右クリックで落とす

【ルール】
・お椀からブロックを3回落とすとゲームオーバー
・塔が高くなると、変な物体が降ってくる
・ゲームオーバーのあと、1回だけ直前に戻れる
```

## サムネイルGIFの撮り方

エディタを閉じて実行します。書き出し先は `unity/Captures/thumbnail.gif` です(Gitの管理外)。

```powershell
$u = 'C:\Program Files\Unity\Hub\Editor\6000.3.3f1\Editor\Unity.exe'
Start-Process $u -ArgumentList '-batchmode','-projectPath','C:\git\block-free-fall\unity','-runTests','-testPlatform','PlayMode','-testFilter','BlockFreeFall.Tests.ThumbnailCapture','-testResults','gif.xml','-logFile','gif.log' -Wait
```

落とす位置と向き、速さ、大きさは `unity/Assets/Tests/PlayMode/ThumbnailCapture.cs` の先頭の数値で変えられます。
